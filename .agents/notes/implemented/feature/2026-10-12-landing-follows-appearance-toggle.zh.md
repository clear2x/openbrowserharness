# Agent Note: 落地页跟随外观切换开关

Status: implemented

[English](2026-10-12-landing-follows-appearance-toggle.md) | 中文

## Problem

用户报告 GitHub Pages 站点上的深浅色开关不起作用。落地页路由把调色板钉死在深色、且两种模式下都生效：`theme/custom.css` 在无条件的 `body:has(.VPHome)` 下重声明了整套 `--vp-c-*`，于是拨动开关只会切换 `html.dark`，首页表面一个像素都不变——body 作用域的深色值在浅色模式下同样生效。文档页切换正常；只有首页路由是死的。

## Decision

落地页现在按外观模式各渲染一套调色板：

- **令牌层**：每个落地页颜色都放进按模式声明一次的 `--landing-*` 自定义属性——浅色值在 `:root`，原先硬编码的深色值在 `html.dark`（同元素特异性，后块胜出）。组件规则只引用令牌；没有任何规则硬编码颜色。
- **深色 pin 收窄作用域**：`--vp-c-*` 重声明（导航、搜索弹窗、卡片）移入 `html.dark body:has(.VPHome)`，浅色模式回退到默认浅色调色板。与模式无关的派生变量（`--vp-nav-bg-color`、`--vp-local-search-*`）仍按 2026-09-28 落地页笔记记录的变量求值规则留在 `body:has(.VPHome)` 上重声明。
- **浅色调色板**：白色表面、墨色发丝线、深青与靛蓝点缀——把素工程语言映射到白底；主 CTA 通过双层背景（padding-box 实色填充加 border-box 渐变）保留渐变描边。
- **轨道艺术画**：`OrbitArt.vue` 读取 `useData().isDark`，按模式换环/火花的 RGB 三元组。动画循环每帧重读调色板；reduced-motion 静态构图经 `watch` 在切换时重绘一次。微弱的静态笔画带按模式的增益系数（白底 ×1.6，墨底 ×1），因为白底比近黑底更快地把发丝笔画洗没。

验证：`website:build` 通过；九断言 Playwright 矩阵（初始浅色、切深、切回、文档页切换、按模式的令牌颜色）通过；两种模式的整页截图经人工核看。深色模式与此前线上站点一致——深色令牌的取值就是原先硬编码的值。

## Alternatives considered

**在首页路由隐藏切换开关。** 否决：报告说的是切换不工作；移除开关等于保留缺陷，还把浅色模式访客留在深色页上。

**落地页保持深色、只让文档页切换。** 否决：导航是共享的，一次导航后浅色导航下压着深色首页，读起来是破损而不是选择。

**按模式复制两份落地页 CSS。** 否决：每条规则两份拷贝必然漂移；令牌层让每个颜色每种模式只声明一次。

## Consequences

外观开关现在切换整站。深色模式不变；浅色模式是全新表面、完全由令牌构成，此后落地页改色只编辑两个令牌块。2026-09-28 落地页笔记中断言旧状态之处（两模式皆深色、极光背景、截图拼贴 hero、仅加载动效）已更新为现状。
