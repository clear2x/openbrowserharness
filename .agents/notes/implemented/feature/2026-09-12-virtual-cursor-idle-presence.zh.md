# Agent Note：虚拟指针 idle 常驻——指针在两次操作之间存活

Status: implemented

[English](2026-09-12-virtual-cursor-idle-presence.md) | 中文

## 问题

霓虹彗星指针只在拟人化手势期间渲染：点击飞行 0.15–0.6 秒，彗尾 1.4 秒散尽，随后 `hideAt` 把指针透明度归零并停止 rAF 循环。agent 一个轮次大部分时间是读操作（搜索、提取、快照——设计上就没有指针），中间穿插亚秒级写操作，于是观看者至多看到一道闪光，两次操作之间页面是死的。可见性抱怨是结构性的，不是外观问题。

## 决策

- 任何手势结束后，指针在落点停留 `IDLE_MS`（8 秒）：透明度 0.6、慢呼吸光晕（sin 周期 520 ms，活跃期 180 ms）、调暗的头部节点。
- 每个入口（`move`/`click`/`key`/`scroll`）都会延长 `idleUntil`；rAF 循环跨越 idle 窗口存活，窗口过后才像以前一样淡出。

## 落选方案

- **拉长飞行动画**：否——差距从来不在闪光时长，而在操作之间的消失。
- **永久常驻指针**：否——用户自己也可能操作页面，一个永久钉住的假指针读起来像 bug；idle 窗口在存在感与不霸占页面之间取得平衡。

## 后果

- 覆盖层的 rAF 会在 idle 窗口内持续运行（每帧两次渐变填充）——有界、廉价、且以与之前相同的清空条件停止，只是延长到 `idleUntil`。
- agent 在页面上的存在感连续：操作时爆发、间歇时呼吸，最后一次操作 8 秒后指针照旧淡出。
