# Agent Note: pi-ai 0.84 migration — thinking-format gate, widened StopReason, abort remap

Status: implemented

English | [中文](2026-09-10-pi-ai-0.84-migration.zh.md)

## Problem

`@earendil-works/pi-ai` 0.82.1 → 0.84.1 (Dependabot #10) widens two contracts the harness compiles against, and silently changes one behavior:

- `PiAiThinkingFormat` gains `baseten`; `THINKING_FORMAT_GATE` in `catalog.ts` is a `Record<PiAiThinkingFormat, true>` drift gate, so the upgrade fails compilation until the new format is classified.
- `StopReason` gains `pending` and `deferred`; `mapStopReason` in `stream.ts` switches exhaustively, so compilation fails there too.
- A **pre-aborted request** — which 0.82 surfaced as `stopReason: 'aborted'` — now arrives as an `error` event whose `errorMessage` is the caller's abort reason (verified empirically: `controller.abort('already stopped')` produced `{kind:'error', code:'PI_AI_ERROR'}`). Unhandled, the harness logs a failed turn the caller deliberately cancelled.

## Decision

- `THINKING_FORMAT_GATE` offers `baseten` — the gate exists to force exactly this classification, and the format joins the name-dispatch set.
- `mapStopReason` covers the widened union: `pending` maps to the harness `aborted` finish (pi-ai initializes AssistantMessage with `stopReason: 'pending'` and overwrites it on the done event; a terminal message still carrying it produced no provider verdict — in practice a pre-dispatch abort), and `deferred` on a terminal event fails loud as `PI_AI_ERROR` (a deferred completion reaching a terminal event is a provider protocol violation).
- `toStreamChunks` takes the caller's `AbortSignal`; an error-kind finish concurrent with an aborted signal remaps to `aborted` (`asAbortedIfCancelled`). Completed `stop` finishes are never remapped — a late abort must not discard a finished turn.

## Alternatives considered

- **Reject the bump and pin pi-ai at 0.82**: rejected — the drift gates would fire on every future bump anyway, and 0.84's contract changes are small and now handled.
- **Detect cancellation by inspecting the abort reason text**: rejected — the reason is caller-owned prose; keying behavior off the signal state is the contract, not off message wording.

## Consequences

- A cancelled request reports `aborted` again, so the harness's interrupted-turn bookkeeping and the side panel's interrupt surface stay truthful on pi-ai 0.84.
- The `THINKING_FORMAT_GATE` drift gate resumes its job: the next pi-ai format addition fails compilation until classified.
- Covered by the existing abort-wiring tests in `adapter.spec.ts` (both pre-abort cases failed before the remap, pass after) and the convert-suite StopReason table.
