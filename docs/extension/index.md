  - title: Humanized page control
    details: Bézier mouse paths with speed jitter, per-keystroke typing, and inertial scrolling — driven through the Chrome DevTools Protocol, never OS-level automation.
  - title: Visible virtual cursor
    details: Every click, keystroke, and scroll renders in the page — a comet-trail cursor with click shockwaves — so you always see what the agent is doing.
  - title: Deep page reading
    details: Snapshots pierce Shadow DOM and iframes. Screenshots feed multimodal models, and in-page scripts verify results.
  - title: Bring your own model
    details: DeepSeek, Zhipu GLM, or any OpenAI-compatible, Anthropic-protocol, or local Ollama endpoint. API keys stay in local extension storage.
  - title: You stay in control
    details: Three permission tiers, per-action approval cards, and exportable session logs. Sensitive steps wait for your click.
