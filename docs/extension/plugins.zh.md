# 用户插件

[English](plugins.md) | 中文

你可以用自己编写的小插件扩展智能体。扩展不内置、不分发任何第三方插件。

## 插件是什么

插件是一个 JavaScript 工厂函数：接收插件上下文，并通过它订阅引擎已声明的事件。

```js
function (ctx) {
  ctx.on('<event>', (payload) => {
    // react to engine events
  })
}
```

源码在扩展面板里编写；扩展把它存在本地，并加载进后续会话。

## 沙箱隔离

插件代码运行在 manifest `sandbox` 字段声明的专用沙箱页面——它是唯一允许 `new Function` 的扩展页面。沙箱没有直接的 `chrome.*` 访问权；插件的一切行为都经由引擎交给它的上下文对象。

## 管理插件

面板列出你的插件及其加载状态。你可以启用或停用插件、删除插件、重写源码。状态变更对后续会话生效。

## 插件失败时

加载时抛错的插件会响亮失败：引擎自动停用它、在插件条目上记录错误，并把信息透出到面板与智能体的插件清单。修好源码重新写入即可清除失败——插件成功加载后错误标识自动消失。
