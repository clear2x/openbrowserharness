# 权限与安全

[English](permissions.md) | 中文

本扩展在**你的 API Key 与你的登录态下驱动真实页面**。下面的控制项决定它在询问你之前能做多少。

## 三档权限

- **每次确认**——每个工具操作都弹出审批卡，等待你的点击。
- **仅变更确认**——读取自由；任何改变页面或浏览器的操作先询问。
- **完全访问**——操作立即执行。新会话默认此档；随时可用输入框里的盾牌芯片收紧。

审批卡在任何操作执行前展示工具与参数，你的选择作用于该次操作。

## 智能体能碰什么

智能体可以在你指向的任何页面上点击、输入、提交——包括你已登录站点上的不可逆操作（下单、发帖、支付）。实用建议：

- 从一次性页面和低风险任务开始。
- 在信任一个任务之前，保持「每次确认」档位。
- 事后回看会话日志——对话与工具结果可导出审计。

## 数据流向一句话

智能体读取的页面内容发送到你配置的 LLM 端点；其余一切——密钥、设置、会话历史——都留在你的机器上。完整表述见[隐私政策](../privacy.zh.md)。
