# 隐私政策

[English](privacy.md) | 中文

OpenBrowserHarness 是一个把 AI 智能体完整运行在浏览器里的扩展。本政策说明扩展处理哪些数据、这些数据去向何处。政策适用于扩展的所有分发渠道，包括 Chrome Web Store 与 Microsoft Edge Add-ons。

## 无服务器、无遥测

扩展不运营任何服务器，不发送遥测、统计或崩溃报告。智能体循环、会话存储与浏览器自动化全部在你的机器上运行。

## 智能体读取的页面内容

你交给智能体任务时，它会读取你指向的页面：无障碍快照、截图、提取的文本与表单字段。智能体把这些内容发送到你自己配置的大模型端点。

扩展内置 DeepSeek 与智谱 GLM API 预设，也接受自定义的 OpenAI 兼容与 Anthropic 兼容端点。请求使用你自己的 API Key。接收方供应商按其自身隐私政策处理内容；扩展开发者不会收到这些内容。

## API Key 与设置

API Key 与扩展设置保存在你机器的 `chrome.storage.local` 中。它们只在你所选端点的请求里作为认证头离开本机。

## 会话历史

对话、工具结果与生成的产物持久化在本机浏览器的 IndexedDB 中。任何内容都不会同步到外部服务。卸载扩展，或在浏览器中清除其站点数据，即删除会话历史。

## 权限

- `debugger` 用于驱动智能体正在操作的标签页——点击、键盘输入、滚动与页面读取——走 Chrome DevTools Protocol。智能体工作期间浏览器会显示"开始调试"横幅；扩展只 attach 任务所指的标签页。
- `tabs` 加 `<all_urls>` 主机权限让你可以把智能体指向任意页面。没有任务时，扩展不会在后台读取或修改页面。
- `storage` 把 Key、设置与会话保存在你的机器上。
- `sidePanel` 渲染智能体面板。`offscreen` 承载长驻智能体进程。`alarms` 为该进程运行内部保活定时器。`sessions` 让智能体重新打开你最近关闭的标签页。
- `activeTab` 在你点击扩展工具栏图标时授予对当前标签页的临时访问。

## 用户插件

你可以自行编写并加载插件。插件代码运行在由 manifest `sandbox` 声明隔离的沙箱页面中，与扩展自身页面隔离。扩展不内置也不分发第三方插件。

## 未成年人

扩展是开发者工具，不面向 13 岁以下未成年人。

## 政策变更

本政策在扩展源码仓库中版本化。数据处理方式的实质变更随引入该变更的版本发布，并同步更新本页。
